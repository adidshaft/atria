## Blocking / needs-change sites (55)

### `Atria/Atria/AtriaHistoricalArchiveDurableStore.swift:1019` — blocker  _(area: direct-file-reads)_

DESTRUCTIVE. `static func repairTornJSONLTail(at url: URL)` opens `FileHandle(forUpdating: url)`, checks whether the LAST byte is 0x0a, and if not scans backwards for the last 0x0a and calls `handle.truncate(atOffset: repaired)`; with no 0x0a anywhere it calls `handle.truncate(atOffset: 0)`. It is invoked on every URL in `existingArchiveURLs` at init (:372), on the cold rebuild path (:407), in `registerArchiveIfNeeded` (:1054), and on the snapshot append-only delta (:1160). The URL list is built by `HistoricalArchive.durableStoreLocked()` (HistoricalArchive.swift:2810-2811) as `[fileURL, legacyFileURL] + rotatedSegmentFileURLs()`; `rotatedSegmentFileURLs()` (HistoricalArchive.swift:7571-7577) appends `catalogRawFileURLs()` (:7602-7610), which maps `chunk.relativePath` — i.e. the ARTIFACT path once `recordCompressedStorage` rewrites it (AtriaHistoricalArchiveCatalog.swift:467). A raw-DEFLATE stream ends in 0x0a only ~1/256 of the time, so on the first durable-store construction after compression this physically truncates the artifact at an arbitrary interior byte — and the plain .jsonl has already been unlinked by the `deleteSourceAfterCommit: true` re-commit. `verifyCompressedStorage` will then fail that chunk permanently. Unrecoverable destruction of user history, not a read failure.

**Fix:** Exclude compressed chunks from `existingArchiveURLs` in `durableStoreLocked()` (filter `chunk.compressedStorage == nil`, or filter pathExtension != AtriaHistoricalSealedJSONLCompression.artifactExtension), AND add a hard guard at the top of `repairTornJSONLTail` refusing to open any `.atria-deflate` path for writing. Both — the store must never be able to reach an immutable artifact with a write handle.

### `Atria/Atria/HistoricalArchive.swift:9089` — blocker  _(area: direct-file-reads)_

### `Atria/Atria/HistoricalArchive.swift:4074` — needs-change  _(area: offsets-and-seek)_
